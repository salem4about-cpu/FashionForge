# FashionForge

**FashionForge** is a mobile-first Progressive Web App (PWA) that empowers fashion designers to customize garments for free. No paywalls, no sign-in required. Works offline and installs like a native app on Android.

## ✨ Features

- Garment templates: T-shirt, hoodie, dress, skirt, trousers, shirt, jacket
- Custom measurements (metric/imperial) with auto size grading
- Style controls: necklines, sleeves, hems, fits, cuts, and toggleable details
- Color palettes and texture library (denim, cotton, silk, satin, knit)
- Texture upload with scale, rotation, opacity, and tiling
- Touch-first UX: pinch-zoom, drag, rotate, multi-select
- Offline data storage via IndexedDB
- PWA install prompt for Android

## 🚀 Tech Stack

- React + Vite
- Tailwind CSS
- Canvas/SVG
- IndexedDB
- GitHub Pages (free hosting)
